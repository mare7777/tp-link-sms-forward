## 資料流程圖

### 1. 發送 SMS 流程

```
使用者
  │
  │ 1. 輸入電話號碼和訊息
  ↓
應用程式 (CLI/API/SMTP)
  │
  │ 2. 驗證輸入
  ↓
Validation Module
  │
  │ 3. 驗證通過
  ↓
Router Client
  │
  │ 4. 連接路由器
  ├─→ fetchEncryptionParams()
  ├─→ parseEncryptionParams()
  ├─→ reconfigureEncryption()
  │   └─→ Encryption Module
  │       ├─→ RSA 加密
  │       └─→ AES 加密
  ├─→ authenticate()
  ├─→ fetchTokenId()
  │
  │ 5. 執行發送命令
  ↓
Router Protocol
  │
  │ 6. 建立資料框架
  ├─→ makeDataFrame()
  │
  │ 7. 加密資料
  ↓
HTTP Client (Axios)
  │
  │ 8. POST /cgi_gdpr
  ↓
TP-Link Router
  │
  │ 9. 處理命令
  │ 10. 透過 SIM 卡發送
  ↓
電信網路
  │
  ↓
接收者手機
```

### 2. 接收 SMS 流程

```
接收者手機
  │
  │ 1. 發送 SMS
  ↓
電信網路
  │
  │ 2. 路由到 SIM 卡
  ↓
TP-Link Router
  │
  │ 3. 儲存到收件匣
  ↓
應用程式 (API/SMS Cat)
  │
  │ 4. 輪詢或查詢
  ├─→ GET /api/v1/sms/inbox
  │
Router Client
  │
  │ 5. 執行查詢命令
  ↓
Router Protocol
  │
  │ 6. 建立查詢框架
  ↓
HTTP Client
  │
  │ 7. POST /cgi_gdpr
  ↓
TP-Link Router
  │
  │ 8. 回傳 SMS 列表
  ↓
Router Protocol
  │
  │ 9. 解析回應
  │ 10. 類型轉換
  ↓
應用程式
  │
  │ 11. 回傳給使用者
  ↓
使用者
```

## 認證流程

```
客戶端請求
  │
  │ Authorization: Basic base64(user:pass)
  ↓
Express Basic Auth Middleware
  │
  ├─ 比對 config.api_users
  │
  ├─ 成功 ──────────────┐
  │                     │
  │ 失敗               │
  ↓                     ↓
401 Unauthorized    速率限制檢查
                        │
                        ├─ 未超過限制
                        │
                        │ 超過限制
                        ↓              ↓
                    執行請求      429 Too Many Requests
                        │
                        ↓
                    回傳結果
```

## 錯誤處理流程

```
請求執行
  │
  ├─ HTTP 錯誤
  │   │
  │   ├─ 500 錯誤 → 重新連接
  │   │   │
  │   │   ├─ reset()
  │   │   └─ execute() 再試一次
  │   │
  │   ├─ 其他錯誤 → sanitizeError()
  │   │   └─ 回傳清理後的錯誤
  │   │
  │   └─ 網路錯誤 → 自動重試
  │       └─ axios-retry (最多 3 次)
  │
  ├─ 驗證錯誤
  │   └─ 回傳 400 Bad Request
  │
  └─ 成功
      └─ 回傳 200 OK
```
